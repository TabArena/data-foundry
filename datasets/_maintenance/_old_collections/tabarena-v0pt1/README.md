# Re-curated Datasets from TabArena-v0.1

This directory contains re-curated datasets from the original TabArena-v0.1 dataset. The curation includes a few changes
compared to TabArena-v0.1, such as log scaling targets, removing constant columns, ensuring the correct dtype for all
columns. The curation is not a 1-to-1 mapping of the original TabArena-v0.1 dataset, but also improves the curation in 
some cases. The current state of the files here may also be out introduced some bugs. Always use the newest versions
published in a data collection of Data Foundry.
