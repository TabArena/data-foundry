## In brief

**Question.** What is the laboratory-reference organic-carbon weight percent of a prepared soil sample from its mid-infrared scan?

**Use case.** A soil spectroscopy laboratory estimates an archived organic-carbon reference from a prepared sample's scan. Evaluation holds out source-ID groups treated as experiment or measurement batches, predicting each sample separately.

**One row.** One archived KSSL soil layer with its averaged mid-infrared spectrum and laboratory-reference label, from the July 2022 source snapshot released in OSSL v1.2.

**Predicted.** Organic carbon in weight percent, estimated analytically from total carbon, with the archived S-preparation reference preferred over N preparation when both exist.

**Known at prediction time.** Absorbance in 1,701 spectral bins from 600 to 4,000 inverse centimetres at intervals of two. Other laboratory outcomes, identifiers and field metadata are not inputs to the source's scan-upload task.

**What the test data stands for.** Whole native KSSL LIMS source-ID groups are held out, with each group treated as an experiment or measurement batch for this benchmark scenario. Some IDs include campaigns or standards. Actual one-to-one batch or physical-profile identity is unverified; the evaluation establishes unseen source-ID groups within this archive.

**Our changes to the source.** We restrict OSSL to KSSL mid-infrared samples, retain the archived reference scale and hold out native KSSL LIMS keys. Rows without a spectrum or reference label cannot form this prediction task.

> **Use case fit: approximate (a stand-in with a known gap).** The accepted target is the archived total-C-based analytical reference. Source-ID groups approximate measurement batches for evaluation, without verified one-to-one experimental-batch or physical-profile identity. Preparation equivalence, agreement with a future assay, and broader instrument, laboratory or geographic transfer remain unverified.

## Curation notes

We start with the lab L1, site L0 and MIR L0 tables of Zenodo record 7599269, v1.2, with archived L0 lab references retained for auditing.

- Prediction point: a prepared scan is available, a new chemical reference is not. Keep all 1,701 raw spectral bins. The source scan-upload service does not require field metadata; other chemistry outcomes and carbon equivalents never enter its inputs (USE-3, LEAK-10).
- Restrict the source code to KSSL.SSL. Join on dataset.code_ascii_txt and id.layer_uuid_txt with one-to-one validation, never by row position or rounded coordinates. Native lims.pedon.id supplies the source-key group, never a model feature (historical KSSL importer, Site information, rename block). Source-key lineage is verified; unique physical-profile identity is not established for all keys, including archive campaigns and bulk standards. No conflicting nonempty coordinate/taxonomy pairs were found; collision is not demonstrated. The source importer kept the first taxonomy per native key before joining, so taxonomy agreement is weak negative evidence of physical uniqueness; missing coordinates further limit that screen.
- The L1 organic-carbon label is an analytical estimate, not a spectroscopy prediction. Archived KSSL L0 S-preparation values take precedence over N preparation; the row-wise coalescence reproduces every KSSL L1 value and missingness mask. The upstream importer had already converted negative laboratory references to missing; this cannot recover their pre-import count.
- Drop rows without any spectrum, and rows with a missing target. Do not clip, scale or nonlinearly transform the reference, discard zero endpoints, average repeated entities or fit a spectral transform over all rows. Raw reference values and source identities remain in the warehouse.
- Hold out native KSSL LIMS source-ID groups for within-archive evaluation, treating each group as an experiment/measurement batch as approved by Myunghwan. Preserve all usable scan/reference rows and score each sample separately; actual experimental batch boundaries are not authenticated by this interpretation. Do not describe every block as a distinct physical profile, or library provenance as proof of physical country of origin. The source-ID grouping is a confirmed task choice; it does not certify physical-profile separation. The benchmark base class supplies deterministic row order and splits.
- Keep the archived reference in raw weight percent and score per-row RMSE, as confirmed by Myunghwan. Dividing by 100 would not add submission flexibility: a method emitting a bounded fraction can convert its output back to percent. The paired check found no material aggregate scaling benefit, but this was not the sole rationale. Preserve zeros and avoid clipping or a nonlinear target transform.
- Version note: this growing-source snapshot was created on Zenodo in February 2023 and uses July 2022 KSSL inputs; the landing page also displays a 2021 publication date. The current record and definition use the 2023 snapshot convention; the historical 2021 landing-page date remains disclosed.

- Metric provenance: the source deliberately tunes inner RMSE with OC in log1p space, and reports original-unit external RMSE. The accepted source-origin raw-percent RMSE cites the external evaluation and keeps these scales distinct; no nonlinear target transform is applied.
- Source overlap: WoSIS documents USDA-NCSS ancestry, and KSSL contains ISRIC-labelled projects. The tasks differ from this MIR calibration; physical aliquot overlap is unmeasured. All 76,813 complete KSSL spectra compared with 8,871 complete other-library spectra show no exact full-grid copies; rescans and partial-grid records remain outside that claim.
- Preparation audit: 55,855 usable XS scans use S references; 20,043 XN scans use N references; 31 XS scans use the source N fallback. Preserve all usable scan/reference rows and source coalescence; identity harmonization is not an analytical-equivalence claim.

- Curator-requested few-band diagnostics on three fixed grouped samples found two-band OLS RMSE 5.98 and five-band OLS 4.01 percentage points, versus 1.96 for retained full-spectrum Ridge. Ten training-fitted PCs retained 98.6% of input variance; PCA10 Ridge RMSE was 4.55 and PCA10 LightGBM 2.77, versus full-spectrum LightGBM 2.43. These are bounded, untuned comparisons on identical 5,000-row train/test samples per fold, not full-data rankings or deployed preprocessing. All 1,701 measured predictors remain.
