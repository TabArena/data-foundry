`dataset.py` reads its raw files from `local-data-warehouse/diamonds/`. To get them:


Then, from the repository root:

```bash
.venv/bin/python -m data_foundry.curation.cli dataset check datasets/_dev/tabarena-v0pt2/diamonds   # pipeline and checks, no UUID; rewrites this page
```
