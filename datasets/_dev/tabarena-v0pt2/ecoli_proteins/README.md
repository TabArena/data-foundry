## Rebuild

`dataset.py` reads its raw files from `local-data-warehouse/ecoli_proteins/`. To get them:

```text
wget https://archive.ics.uci.edu/static/public/39/ecoli.zip && unzip ecoli.zip && rm ecoli.zip ecoli.names
mkdir -p local-data-warehouse/ecoli_proteins && mv ecoli.data local-data-warehouse/ecoli_proteins/
```

Then, from the repository root:

```bash
.venv/bin/python -m data_foundry.curation.cli dataset check datasets/_dev/tabarena-v0pt2/ecoli_proteins   # pipeline and checks, no UUID; rewrites this page

```
